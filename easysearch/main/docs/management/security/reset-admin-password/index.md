# 重置管理员账号密码

> 本功能所需 Agent 版本：>=1.32.0

在 Agent 服务管理页面，点击所要更改密码的集群的「操作」按钮，在下拉菜单中选择
「重置管理员密码」：

{{% load-img "/img/management/security/reset-admin-password/image-1.png" %}}

在弹窗中输入创建集群时设置的管理员证书口令和新密码，点击确认即可：

{{% load-img "/img/management/security/reset-admin-password/image-2.png" %}}
