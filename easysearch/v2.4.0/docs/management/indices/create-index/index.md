# 新增索引

在「索引」列表页点击「新增」，进入新增索引页面。除填写名称、索引设置外，页面内置**可视化 Mapping 编辑器**：以字段树的方式编辑字段类型与参数，支持多字段、嵌套对象、批量添加字段，并可直接从**索引模板**或**已有索引**一键导入配置，创建时还能顺便关联别名。

## 操作步骤

1. **进入新增索引页面**：在左侧导航栏点击「索引」，进入索引列表页，点击右上角的「新增」按钮。

   {{% load-img "/img/management/indices/create-index/image-1.png" %}}

2. **填写索引名称**：名称为必填项，命名规则见下方补充说明。页面自上而下依次为：名称、索引设置、Mapping 设置、别名。

3. **从模板或已有索引导入（可选）**：点击页面右上角的「导入」按钮

   {{% load-img "/img/management/indices/create-index/image-2.png" %}}

   在弹窗中统一选择配置来源，选中一行后点击「应用」：

   {{% load-img "/img/management/indices/create-index/image-3.png" %}}

4. **可视化编辑 Mapping**：Mapping 设置区域由顶部的全局配置和下方的字段树组成。

   {{% load-img "/img/management/indices/create-index/image-4.png" %}}

   - **全局配置**：「动态 Mapping」（`true` / `false` / `strict` / `runtime`）、「日期探测」、「数字探测」开关，以及「动态日期格式」（多个格式用逗号分隔，如 `yyyy-MM-dd||epoch_millis`）。
   - **字段行**：每个字段占一行，包含字段名、类型和操作按钮（参数 / 删除 / 添加多字段）。类型下拉框支持搜索，覆盖全部字段类型（`keyword`、`text`、`long`、`date`、`object`、`nested`、`dense_vector` 等）。
   - **参数**：点击行内「参数」按钮，在弹窗中编辑「通用参数」与「类型专属参数」，点击「确定」后保存生效。
   - **多字段（multi-fields）**：为同一个字段的值附加第二种索引方式，例如为 `title`（`text`）添加 `raw`（`keyword`）多字段，即可既做全文检索又做精确聚合。多字段不能再嵌套子字段。
   - **嵌套字段**：`object` / `nested` 类型的字段行会显示「添加字段」按钮，点击后逐层添加子字段，形成 `a.b.c` 的层级结构。
   - 字段名不允许包含 `.`，层级关系请通过子字段表达。

5. **批量添加字段**：点击字段列表底部的「批量添加」按钮，一次录入多个同类型字段。

   {{% load-img "/img/management/indices/create-index/image-5.png" %}}

   点击「添加」按钮即可:

   {{% load-img "/img/management/indices/create-index/image-6.png" %}}

   - 选择统一的「字段类型」，在「字段列表」中输入字段名，**以空格或换行分隔**。
   - 支持 `a.b.c` 形式的嵌套路径，中间层级会自动创建为 `object` 类型。
   - 输入内容实时校验：与已有字段冲突（如 `a` 已是 `text` 字段，再输入 `a.b`）、字段重复、非法路径（连续点号、空段）都会即时提示；存在任何问题时整批不会被添加，修正后重试。

6. **JSON 模式（可选）**：点击「JSON 编辑」可切换为直接编辑 Mapping DSL；点击「可视化编辑」切回字段树，两种模式内容保持同步。GUI 未覆盖的高级内容（`dynamic_templates`、`_source`、`_meta`、未知字段类型等）在两种模式间往返后原样保留，仅可在 JSON 模式中编辑。

   {{% load-img "/img/management/indices/create-index/image-7.png" %}}

7. **关联别名（可选）**：在「别名」多选框中勾选需要关联的别名。只能选择集群中已存在的别名，不支持在此新建；从索引导入时其别名已自动预勾选，可再自行增删。

8. **提交创建**：点击「新增」按钮完成创建，成功后自动返回索引列表。

## 补充说明

- **索引命名规则**：索引名称必须为小写字母，不能以 `_`、`-` 或 `+` 开头，不能包含空格、逗号、`#`、`:`、`"`、`*`、`?`、`<`、`>`、`|`、`/` 等特殊字符，长度不得超过 255 个字节。
- 索引创建后，**主分片数不可修改**（需通过拆分或重建索引实现变更），副本数可随时调整，请提前规划好分片数量。
- **Mapping 校验**：提交前会拦截存在问题的 Mapping 并给出提示，包括：存在未命名的字段、存在重名字段、`alias` 字段缺少目标路径（path）、向量字段缺少 `dims`。
